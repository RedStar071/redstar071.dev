## 🐺 a bit about me

- i look after [**WolfStar**](https://wolfstar.rocks), a Discord moderation bot, and its dashboard
- i maintain [**Stars Components**](https://stars-components.js.org), an HTTP-first TypeScript framework for Discord apps, and [**newt-ui**](https://newtui.dev), a Discord-styled component library
- i write TypeScript, Vue and Nuxt, mostly in the open
- i make frameworks, plugins and UI kits for other devs, like [unplugin-version-injector](https://github.com/RedStar071/unplugin-version-injector)
- i'm based in Italy 🇮🇹
